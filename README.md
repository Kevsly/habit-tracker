# Habit Tracker

A simple CLI habit tracker for coding sessions.

## Features
- Mark/unmark coding sessions by day
- View current week progress
- Track streaks (current and longest)
- Set weekly goal
- View stats (busiest weekday, total sessions)

## Usage
Run with Python:
`ash
python habit_tracker.py
`

## Data
Data is stored in data.json (ignored by git).
